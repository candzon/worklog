## Step-by-Step Installation

### **STEP 1: Extract Project**

1. Open File Explorer (Windows) or Finder (Mac)
2. Navigate to the folder where you downloaded the ZIP file
3. **Right-click** on `project-assignment-iotbay-marketplace-workshop09-group1-main.zip`
4. Select **"Extract All..."** or **"Extract Here"**
5. Wait for extraction to complete
6. You will get a folder named:
   ```
   project-assignment-iotbay-marketplace-workshop09-group1-main
   ```

---

### **STEP 2: Open Terminal/Command Prompt**

#### **Windows:**
1. Press **Windows + R**
2. Type `cmd` and press Enter
3. Or press **Windows + X** and select **"Windows PowerShell"**

#### **Mac/Linux:**
1. Press **Command + Space** (Mac) or **Ctrl + Alt + T** (Linux)
2. Type `terminal` and press Enter

---

### **STEP 3: Navigate to Project Folder**

In terminal, type:

```bash
cd path/to/folder/project-assignment-iotbay-marketplace-workshop09-group1-main
```

**Example:**
- Windows: `cd C:\Users\YourName\Downloads\project-assignment-iotbay-marketplace-workshop09-group1-main`
- Mac/Linux: `cd ~/Downloads/project-assignment-iotbay-marketplace-workshop09-group1-main`

**Tip:** You can **drag & drop** the project folder into the terminal to auto-fill the path.

Verify your location:
```bash
# Windows
dir

# Mac/Linux
ls
```

You should see folders: `backend`, `Frontend`, `db`, etc.

---

### **STEP 4: Install Python Dependencies**

In the project root folder, run:

```bash
pip install -r requirements.txt
```

**Or if using `pip3`:**
```bash
pip3 install -r requirements.txt
```

**Installation process:**
1. pip will download and install:
   - Flask (web framework)
   - Flask-CORS (for cross-origin requests)
   - Selenium (for testing)
2. Wait until you see "Successfully installed..."
3. Verify installation:
   ```bash
   pip list | grep -i flask
   # Or in Windows PowerShell:
   pip list | findstr /i flask
   ```
   Should show: `Flask` and `Flask-Cors`

**If errors occur:**
- Ensure Python and pip are in PATH
- Try using `python -m pip install -r requirements.txt`
- Or install individually:
  ```bash
  pip install flask
  pip install flask-cors
  pip install selenium
  ```

## Database Setup

### **STEP 5: Create SQLite Database**

There are 2 ways to setup the database:

#### **Method 1: Using Automated Script (RECOMMENDED)**

1. Make sure you're in the **root project folder**
2. Run the setup script:
   ```bash
   python backend/setup_db.py
   ```
   
3. **Expected output:**
   ```
   Menyiapkan database baru di: /path/to/project/db/app.db
   Mengeksekusi /path/to/project/db/schema.sql...
   Mengeksekusi /path/to/project/db/seed.sql...
   Sukses! Database berhasil dibuat dan diisi. Mantap!
   ```

4. Verify database file was created:
   ```bash
   # Windows
   dir db\app.db
   
   # Mac/Linux
   ls -lh db/app.db
   ```
   Should show `app.db` file with size ~4-8 KB.

---

#### **Method 2: Manual with DB Browser for SQLite**

If Method 1 fails, use manual method:

1. **Install DB Browser for SQLite:**
   - Download from: [https://sqlitebrowser.org/dl/](https://sqlitebrowser.org/dl/)
   - Install with default settings
   
2. **Open DB Browser:**
   - Click **"New Database"**
   - Navigate to `db/` folder in your project
   - File name: `app.db`
   - Click **Save**

3. **Execute Schema:**
   - Click **"Execute SQL"** tab
   - Click **"Open SQL file"** (folder icon)
   - Select `db/schema.sql` file
   - Click **"Execute SQL"** (play icon)
   - Should show: "Query executed successfully"

4. **Execute Seed Data:**
   - Still in **"Execute SQL"** tab
   - Click **"Open SQL file"** again
   - Select `db/seed.sql` file
   - Click **"Execute SQL"**
   - Should show: "Query executed successfully"

5. **Save Database:**
   - Click **"Write Changes"** or press **Ctrl+S**
   - Close DB Browser

6. **Verify Data:**
   - Open DB Browser again
   - Open database `db/app.db`
   - Click **"Browse Data"** tab
   - Select **"devices"** table
   - Should have 5 IoT devices (ESP32, DHT22, Raspberry Pi, etc.)

## Running the Application

### **STEP 6: Run Backend (Flask Server)**

1. **Open a new Terminal/CMD** (don't close the previous terminal)
2. Navigate to project folder:
   ```bash
   cd path/to/folder/project-assignment-iotbay-marketplace-workshop09-group1-main
   ```

3. **Run Flask server:**
   ```bash
   python -m backend.app
   ```
   
   **Or if using `python3`:**
   ```bash
   python3 -m backend.app
   ```

4. **Expected output:**
   ```
    * Serving Flask app 'backend.app'
    * Debug mode: on
   WARNING: This is a development server. Do not use it in a production deployment.
    * Running on http://127.0.0.1:8080
   Press CTRL+C to quit
    * Restarting with stat
    * Debugger is active!
   ```

5. **Backend successfully running at:** `http://127.0.0.1:8080`

**IMPORTANT:**
- **DO NOT CLOSE** this terminal while using the application
- If you get "Address already in use" error, port 8080 is occupied:
  ```bash
  # Windows - kill process on port 8080
  netstat -ano | findstr :8080
  taskkill /PID <PID_NUMBER> /F
  
  # Mac/Linux
  lsof -ti:8080 | xargs kill -9
  ```

---

### **STEP 7: Run Frontend (Static Server)**

1. **Open another new Terminal/CMD** (now 2 terminals are open)
2. Navigate to **Frontend** folder:
   ```bash
   cd path/to/folder/project-assignment-iotbay-marketplace-workshop09-group1-main/Frontend
   ```

3. **Run simple HTTP server:**
   
   **Python 3.x:**
   ```bash
   python -m http.server 8000
   ```
   
   **Python 2.x (if using old version):**
   ```bash
   python -m SimpleHTTPServer 8000
   ```

4. **Expected output:**
   ```
   Serving HTTP on 0.0.0.0 port 8000 (http://0.0.0.0:8000/) ...
   ```

5. **Frontend successfully running at:** `http://127.0.0.1:8000`


## Troubleshooting

### **1. Error: "ModuleNotFoundError: No module named 'flask'"**

**Solution:**
```bash
pip install flask flask-cors selenium
```

---

### **2. Error: "Address already in use" (Port 8080 or 8000 occupied)**

**Windows:**
```bash
# Check who's using port 8080
netstat -ano | findstr :8080

# Kill process (replace <PID> with the number shown)
taskkill /PID <PID> /F
```

**Mac/Linux:**
```bash
# Kill process on port 8080
lsof -ti:8080 | xargs kill -9

# Kill process on port 8000
lsof -ti:8000 | xargs kill -9
```

**Or use different port:**
```bash
# Backend: edit backend/app.py, change port in lines 75-79
# Frontend: run with different port
python -m http.server 8001
```

---

### **3. Error: "Database is locked"**

**Cause:** File `app.db` is open in another application (DB Browser, Excel, etc.)

**Solution:**
1. Close all applications accessing `app.db`
2. Restart backend server
3. If still error, delete `db/app.db` and run `python backend/setup_db.py` again

---

### **4. CORS Error in Browser Console**

**Error:** `Access to fetch at 'http://127.0.0.1:8080/...' has been blocked by CORS policy`

**Solution:**
1. Ensure backend is on port **8080** and frontend on port **8000**
2. Don't open HTML files directly (double-click), must use HTTP server
3. Restart backend server

---

### **5. ChromeDriver Error during Testing**

**Error:** `selenium.common.exceptions.WebDriverException: 'chromedriver' executable needs to be in PATH`

**Solution:**
1. Download ChromeDriver: [https://chromedriver.chromium.org/downloads](https://chromedriver.chromium.org/downloads)
2. Ensure ChromeDriver version matches Google Chrome version
3. **Windows:** Copy `chromedriver.exe` to `C:\Windows\System32\`
4. **Mac:** 
   ```bash
   sudo mv chromedriver /usr/local/bin/
   sudo chmod +x /usr/local/bin/chromedriver
   ```
5. **Linux:**
   ```bash
   sudo mv chromedriver /usr/bin/
   sudo chmod +x /usr/bin/chromedriver
   ```

---

### **6. Frontend Cannot Load Data from Backend**

**Check:**
1. Backend running at `http://127.0.0.1:8080`? Open in browser, should show 404 error or JSON response
2. Frontend must use HTTP server (port 8000), not open HTML files directly
3. Open Browser Console (F12) → Console tab, check for errors
4. Network tab → check if API requests fail or succeed

**Common fixes:**
- Restart backend & frontend
- Clear browser cache (Ctrl+Shift+Del)
- Use Incognito Mode

---

### **7. Device Data Not Showing**

**Solution:**
1. Check database is populated with seed data:
   ```bash
   python backend/setup_db.py
   ```
2. Open DB Browser → Check `devices` table has 5 records
3. Test backend endpoint directly in browser:
   ```
   http://127.0.0.1:8080/devices/all
   ```
   Should return JSON with device list

## Database Schema

### **Tables:**

| Column | Type | Description |
|--------|------|-------------|
| user_id | INTEGER (PK) | Unique user ID |

|--------|------|-------------|
| device_id | INTEGER (PK) | Unique device ID |

| Column | Type | Description |
|--------|------|-------------|
| order_id | INTEGER (PK) | Unique order ID |
| user_id | INTEGER (FK) | Reference to users |
| total_price | DECIMAL(10,2) | Total order price |
| name | VARCHAR(100) | Order name/description |
| status | VARCHAR(20) | saved/paid/cancelled |

#### **order_items**
| Column | Type | Description |
|--------|------|-------------|
| order_item_id | INTEGER (PK) | Unique item ID |
| order_id | INTEGER (FK) | Reference to orders |

| quantity | INTEGER | Quantity ordered |

#### **payment_methods**
| Column | Type | Description |
|--------|------|-------------|
| payment_method_id | INTEGER (PK) | Unique method ID |
| user_id | INTEGER (FK) | Reference to users |
| type | VARCHAR(50) | credit_card/debit/paypal |

#### **payments**
| Column | Type | Description |
|--------|------|-------------|
| payment_id | INTEGER (PK) | Unique payment ID |
| order_id | INTEGER (FK) | Reference to orders |
| payment_method_id | INTEGER (FK) | Reference to payment_methods |
| amount | DECIMAL(10,2) | Payment amount |

#### **shipments**
| Column | Type | Description |
|--------|------|-------------|
| shipment_id | INTEGER (PK) | Unique shipment ID |
| order_id | INTEGER (FK) | Reference to orders |

#### **access_logs**
| Column | Type | Description |
|--------|------|-------------|

## API Endpoints

### **Authentication**
- `POST /auth/register` - Register new user
- `POST /auth/login` - Login
- `POST /auth/logout` - Logout
- `GET /auth/me` - Get current user session

### **Devices**
- `GET /devices/all` - Get all devices
- `GET /devices/<id>` - Get device by ID
- `POST /devices/create` - Create device (Admin only)
- `PUT /devices/<id>` - Update device (Admin only)
- `DELETE /devices/<id>` - Delete device (Admin only)

### **Orders**
- `GET /orders/my` - Get user's orders
- `GET /orders/all` - Get all orders (Admin only)
- `POST /orders/create` - Create new order
- `PUT /orders/<id>` - Update order status

### **Payments**
- `GET /payments/my` - Get user's payments
- `GET /payments/all` - Get all payments (Admin only)
- `POST /payments/create` - Process payment

### **Shipments**
- `GET /shipments/all` - Get all shipments (Staff/Admin only)
- `POST /shipments/create` - Create shipment (Staff/Admin only)
- `PUT /shipments/<id>` - Update shipment status (Staff/Admin only)

## Security Notes

**WARNING - SECURITY CONCERNS:**

This application is an **academic/learning project**, several security features are not implemented:

1. **Passwords not hashed** - stored as plaintext in database
2. **Session secret key hardcoded** - not secure
3. **No input sanitization** - vulnerable to SQL injection & XSS
4. **No rate limiting** - vulnerable to brute force attacks
5. **No HTTPS** - data transmitted in plaintext

**For production:**
- Use `bcrypt` for password hashing
- Implement `Flask-Login` for session management
- Use `Flask-WTF` for CSRF protection
- Implement input validation & sanitization
- Use environment variables for sensitive data
- Enable HTTPS with SSL certificate
- Implement rate limiting with `Flask-Limiter`
